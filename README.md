> **English, in short.** PhotoCraft by Vetro is an unofficial fork of
> [storytold/photocraft](https://github.com/storytold/photocraft). The Rust engine is unchanged;
> the app is a new native Windows shell in C++ (Direct3D 11 + Direct2D + DirectComposition) that
> talks to the engine through a small C ABI bridge (`crates/bridge`). Floating glass docks,
> spring motion, Phosphor icons, Photoshop-style interaction, English and Russian UI. The original
> README is kept as [README.photocraft.md](README.photocraft.md).

## Чем отличается от оригинала

| | PhotoCraft (оригинал) | PhotoCraft by Vetro |
|---|---|---|
| Интерфейс | egui / eframe на wgpu (immediate mode), один код на macOS, Windows, Linux, вебе | Нативная оболочка на C++ для Windows: Direct3D 11 → Direct2D 1.1 → DirectComposition, свои классы виджетов (retained) |
| Внешний вид | Классическая раскладка в стиле Photoshop с закреплёнными панелями | Стиль Vetro: фото — фон всего окна, вокруг плавающие доки из матового стекла (живое размытие сцены, оттенок, шум, кромка, тень), иконки Phosphor, пружинная анимация, меню вырастают из кнопки |
| Движок | `crates/*`: слои, кисти, PSD, фильтры, история, 890+ команд | Тот же движок, без изменений (синхронизирован с `main` оригинала на 2026-10-13) |
| Связь с движком | Прямые вызовы Rust | C ABI-мост `crates/bridge` (`photocraft_bridge.dll`): команды по id, снимки документа, живой мазок кисти, GPU-холст, каталог меню и переводов |
| Холст | wgpu-композитор в окне egui | Тот же GPU-композитор движка на Direct3D 12 рисует в текстуру, общую с Direct3D 11 оболочки; обновление только изменённых областей; запасной CPU-путь |
| Цвет | Управление цветом движка | Профиль ICC монитора окна → таблица движка → эффект 3D LUT Direct2D на холсте |
| Отзывчивость | — | Команды, превью диалогов и сохранение идут в фоне; интерфейс живёт, пока движок считает |
| Языки | 20 языков | English и русский (переключение щелчком по логотипу); русский берётся из каталога оригинала, строки оболочки переведены отдельно |
| Платформы | macOS, Windows, Linux, FreeBSD, веб | Только Windows 10/11 x64 (оболочка); движок по-прежнему кроссплатформенный |

Всё, что было в оригинале, осталось на месте: egui-приложение (`apps/photocraft`), CLI, веб-сборка
и MCP-сервер собираются как раньше. Vetro добавляет только `crates/bridge` и `vetro/`.

## Что уже сделано (0.8.2-v01)

**Оболочка и стиль**
- Плавающие перетаскиваемые доки: бренд и меню, параметры инструмента, инструменты с выпадающими
  группами, «Свойства / Коррекция», «Слои / История», строка состояния, масштаб.
- Единый рецепт матового стекла; пружины на всём, что движется; меню-морф из кнопки с каскадом
  строк; Reduce Motion схлопывает анимацию.
- Классы взаимодействия вместо кода «по месту»: кнопки, слайдер, переключатель, сегменты,
  выпадающий список, меню с подменю, вкладки, док, тост, подсказка, поле цвета, редактор кривой
  и диалоги, генерируемые из описания параметров команды.

**Холст**
- GPU-композитор движка через общую текстуру D3D12 ↔ D3D11, обновление по damage; при больших
  документах — CPU-путь с уровнями детализации.
- Цветоуправление по профилю монитора; панорама и масштаб на пружинах.

**Инструменты** (работают через команды движка)
- Кисть, карандаш и ластик с живым мазком движком; сглаживание; Alt+колесо и Alt+ПКМ —
  размер и жёсткость.
- Ретушь: точечная и обычная восстанавливающая кисть, штамп (Alt — источник, Aligned), удаление,
  размытие, резкость, палец, осветлитель, затемнитель, губка и другие.
- Выделения: прямоугольное и овальное, лассо, магнитное лассо, быстрое выделение, волшебная
  палочка, выделение объектов, режимы добавления и вычитания.
- Рамка и перспективная рамка; перо, свободное перо и перо кривизны; выделение контуров;
  действия контура в меню ПКМ.
- Фигуры: прямоугольник, скруглённый прямоугольник, эллипс, треугольник, многоугольник,
  звезда, линия.
- Горизонтальный и вертикальный текст, градиент, заливка, пипетка (свой курсор), цветовой
  эталон, линейка, заметки, счёт, монтажная область.

**Редакторы и диалоги**
- Свободное трансформирование: масштаб, поворот, искажение, деформация сеткой Безье; живое
  превью движком; Ctrl+Z по шагам.
- Camera Raw (вкладки, HSL, цветокоррекция, кривая), Кривые с точками, Пластика (инструменты
  на холсте, маска заморозки), Стиль слоя, все фильтры и коррекции движка — диалогами с
  живым превью.

**Слои**
- Меню ПКМ, двойной щелчок (имя — переименовать, строка — стиль слоя), Alt+щелчок между
  слоями — обтравочная маска, перетаскивание (Alt — копия), видимость, режимы, непрозрачность.

**Меню и файлы**
- Полное меню Photoshop из каталога движка с доступностью и горячими клавишами.
- Открытие и сохранение (PSD, PNG, JPEG, TIFF, WebP, `.pcraft` и другие форматы движка),
  системные диалоги, перетаскивание файлов.
- Контекстные меню холста, пера, трансформирования, слоёв.

Подробно, с тем, что проверено вживую, — [vetro/PLAN.md](vetro/PLAN.md).

## Архитектура

```
VetroView — C++          vetro/shell      окно, доки, виджеты, инструменты, анимация, стекло
      ↑↓ C ABI           crates/bridge    photocraft_bridge.dll: команды, снимки, мазок, GPU-холст
PhotoCraft Engine — Rust crates/*         слои, кисти, PSD, фильтры, история (без изменений)
      ↓
GPU: Direct3D 11 + Direct2D + DirectComposition (оболочка), wgpu на Direct3D 12 (холст)
```

## Сборка и запуск

Нужны Rust (stable), Visual Studio 2022 с компонентом «Разработка классических приложений на
C++» (x64), CMake и Ninja (входят в Visual Studio).

```powershell
vetro\build.ps1 -Run -Open "C:\path\to\photo.jpg"
```

Результат — `vetro\dist\PhotoCraftVetro.exe` рядом с `photocraft_bridge.dll`. Готовая сборка —
на странице [Releases](https://github.com/Phnem/photocraft-by-Vetro/releases).

## Roadmap

### 1. Паритет с Photoshop в оболочке

Движок уже умеет почти всё, чего не хватает интерфейсу, поэтому это в основном работа оболочки.
Разбор недостающего — [vetro/PS_GAPS.md](vetro/PS_GAPS.md), план по тикетам VT-24…VT-68 —
[vetro/TICKETS.md](vetro/TICKETS.md):

1. **Клавиши и жесты:** стрелки, Alt-копия при перемещении, цифры непрозрачности, Shift+[ ] —
   жёсткость, прямолинейное лассо по точкам, мелочи панели слоёв.
2. **Обмен с системой:** буфер обмена Windows, перетаскивание файла слоем, вкладки документов,
   недавние файлы.
3. **Панель параметров и трансформирование:** меню и числа трансформирования, опорная точка,
   параметры фигур, выделений, пипетки, градиента, рамки, пера.
4. **Кисти, слои, коррекция:** палитра кисти по ПКМ, панели «Кисти» и «Настройки кисти»,
   свойства корректирующих слоёв, маски, замки, эффекты под слоем, смарт-фильтры.
5. **Текст:** редактирование на холсте, шрифты, панели «Символ» и «Абзац».
6. **Линейки, направляющие, сетка, привязка.**
7. **Панели:** своя палитра цветов, «Цвет», «Образцы», «Каналы», «Контуры», история со снимками,
   «Навигатор», «Гистограмма», «Инфо».
8. **Рабочие среды:** «Выделение и маска», быстрая маска, режимы экрана, контекстная панель
   задач, окна «Создать» и «Экспортировать как».

### 2. Эксперименты с ИИ

Подробный план — [vetro/AI_PLAN.md](vetro/AI_PLAN.md). Гибрид: локальные модели (ONNX Runtime на
видеокарте) — для точных масок и ретуши, OpenRouter — для понимания сцены и генерации.
Результат ИИ — обычные слои, маски и выделения, всё неразрушающее.

- **Умное выделение с подсказками:** люди, небо, вода, горизонт — щелчком (SAM 2.1).
- **Удаление фона и объектов:** BiRefNet, LaMa.
- **Генеративная замена элемента и расширение кадра:** генераторы изображений через OpenRouter,
  вклейка только внутри маски с подгонкой цвета.
- **Ретушь портрета:** поиск и разметка лица, сглаживание кожи с сохранением текстуры.
- **Восстановление старых фото:** царапины, шум, лица, колоризация, увеличение.
- **Текстовые команды** («сделай теплее и подними тени»): LLM составляет план из команд движка.

### 3. Остальные возможности движка

У движка больше 890 команд; меню уже открывает их все, а своё взаимодействие на холсте и в
панелях получают по очереди. Следующие на очереди после паритета: марионеточная деформация и
деформация перспективы на холсте, галерея фильтров, анимация и видеослои, срезы и экспорт
ресурсов, 3D-LUT и цветопроба, симметрия рисования, наборы инструментов, операции (actions) и
пакетная обработка, плагины WebAssembly.
