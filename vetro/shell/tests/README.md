# Проверка PhotoCraft by Vetro

Из корня PhotoCraft. Тестовые исполняемые файлы собираются только с ключом `-Tests`
(обычная сборка кладёт в `dist/` одно приложение):

```powershell
vetro\build.ps1 -Tests -OutputDir (Resolve-Path .\vetro\dist\milestone3)
ctest --test-dir vetro\build --output-on-failure
```

`-OutputDir` лучше давать абсолютным путём: относительный считается от текущей папки.
`-Run` запускает собранное приложение с видимым окном, `-Hidden` — без окна (для автоматизации).

Три набора, все создают отдельный движок и скрытое Win32-окно. Они вызывают настоящие
обработчики оболочки, виджеты, очередь заданий и C ABI. Документы синтетические;
открытый экземпляр приложения, файлы пользователя и сохранённые настройки не меняются.
Клавиши-модификаторы в тестах подаются в состояние только тестового UI-потока.

| Набор (ctest) | Исполняемый файл | Что проверяет | Проверок CPU / GPU |
|---|---|---|---|
| `milestone1` | `VetroInteractionTests` | Веха 1 (VT-24–VT-30) | 304 / 307 |
| `milestone2` | `VetroSystemTests` | Веха 2 (VT-31–VT-34) | 330 / 332 |
| `milestone3` | `VetroParameterTests` | Веха 3 (VT-35–VT-44) | 2016 / 2018 |

По умолчанию проверяется CPU-холст. GPU-путь на доступном D3D12-адаптере (общая
GPU-текстура; автоматический переход на CPU не считается успешной GPU-проверкой):

```powershell
$env:VETRO_TEST_GPU = '1'
try {
  foreach ($suite in 'VetroInteractionTests', 'VetroSystemTests', 'VetroParameterTests') {
    & ".\vetro\dist\milestone3\$suite.exe" ".\vetro\build\qa-gpu-$suite"
    if ($LASTEXITCODE) { throw "$suite failed on the GPU" }
  }
} finally {
  Remove-Item Env:\VETRO_TEST_GPU
}
```

Снимки интерфейса на русском сохраняются в папку, указанную аргументом (по умолчанию —
`vetro/build/qa*`, дерево сборки игнорируется git).

## Веха 1 (`VetroInteractionTests`)

Сдвиг слоёв и выделения с объединением истории (8/16/32 бит), отмена, копирование и
ограничения перемещения, управляющие элементы, кисть и временные состояния, выделения от
центра и с перемещением рамки, прямолинейное лассо, группы и глазки, загрузка прозрачности,
Delete и сброс на кнопки панели, открытие смарт-объекта, временные инструменты, масштаб и
поворот, имена слоёв и все подписи/варианты окна «Стиль слоя». Снимок кадра также проверяет,
что холст показывает последние пиксели.

## Веха 2 (`VetroSystemTests`)

Реальный буфер Windows с PNG/DIBV5/DIB, прозрачность, порядок строк, палитра, bitfields,
повреждённые размеры/маски/буферы; C ABI и вставка/копирование в документах 8/16/32 бит;
WM_DROPFILES с Unicode-путём, координатами повёрнутого холста и Shift; вкладки, переполнение,
изменение порядка (в том числе перетаскивание вправо, влево и за последнюю вкладку),
закрытие с Save/Discard/Cancel, отмена Save As и ошибка записи; открытие недавнего файла и
сохранение MRU между экземплярами хранилища. Копирование слоя и композиции проверяется по
различающимся пикселям. Проверяется также вставка после Purge Clipboard.

Буфер Windows изолирован через `CreateWindowStation`/`CreateDesktop` до создания окон и
COM; пользовательский буфер не читается и не изменяется. Тест использует отдельный ключ
HKCU и синтетические файлы в заданной папке сборки.
Контракты Windows: [Clipboard Operations](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-operations),
[BITMAPV5HEADER](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/ns-wingdi-bitmapv5header).

Замер подготовки/публикации/чтения буфера на синтетическом RGB-шуме 24 Мп:

```powershell
vetro\dist\milestone3\VetroSystemTests.exe .\vetro\build\qa-milestone2 --benchmark
```

Этот вариант дополнительно проверяет точное совпадение 96 МБ RGBA после чтения и продолжение
кадров интерфейса во время фонового кодирования. Результат — `clipboard-perf.txt` в папке
снимков. Замер 2026-10-13: подготовка 3014 мс, публикация 45,4 мс, чтение 255 мс; 408 кадров
во время подготовки, самый длинный 19,3 мс. Это один синтетический замер Vetro, не результат
проверки бюджета или регрессии egui. Внешний буфер — RGBA8; внутри приложения собственная
копия сохраняет исходную глубину цвета. Входные размеры ограничены 32768 px по стороне и
256 МиБ RGBA, превышение и неправильная длина буфера возвращают ошибку.

## Веха 3 (`VetroParameterTests`)

Все проверки идут по документам 8/16/32 бит.

- **Трансформирование (VT-35–37, VT-41).** Режимы меню ПКМ (Масштаб, Поворот, Наклон,
  Искажение, Перспектива — каждый отмечается в меню и перехватывает протяжку), Отразить,
  Повернуть на 180°; числа X/Y/Ш/В/угол/наклон и связь пропорций; опорная точка (Alt+щелчок);
  Ctrl+край — наклон, Ctrl+Alt+Shift+угол — симметричная перспектива по горизонтали и по
  вертикали; поле «Наклон» и «В» читают рамку, а не отдельный счётчик; пустой щелчок не
  добавляет шаг отмены; стрелки двигают рамку; повтор (Ctrl+Shift+T), копия, трансформация
  выделения (маска без изменения пикселей, одним шагом).
- **Деформация (VT-36).** Все 16 стилей дают свою сетку, сетки 3×3 / 4×4 / 5×5, разбиение
  крестом, по горизонтали и по вертикали, локальная отмена, одна запись в истории.
- **Фигуры и выравнивание (VT-38, VT-39).** Размеры, заливка, обводка (толщина, пунктир,
  расположение), радиусы по одному углу (Alt), операции с контуром; выравнивание по холсту и
  выделению; все восемь кнопок распределения ровно раскладывают три слоя.
- **Выделения (VT-40).** Образцы палочки, сглаживание, «Все слои», сохранение/загрузка
  выделения, пункты контекстного меню, запуск «Трансформировать выделение» из меню,
  кнопки «Выделить предмет» и «Выделение и маска».
- **Пипетка и градиент (VT-42).** Размер и источник образца, Alt — фон; заливка-градиент с
  редактируемыми точками и остановками, один шаг истории на протяжку, пресеты по группам,
  редактор (Отмена/Применить), классический градиент; простой щелчок не двигает маркеры;
  слой градиента получает имя на языке интерфейса одним шагом.
- **Рамка (VT-43).** Наложения (O), поворот за рамкой с привязкой 15°, «Выпрямить»,
  пропорции и выходной размер (размер фиксирует пропорции, «Очистить» и выбор пропорции
  сбрасывают его, кадрирование не растягивает), разрешение, «Удалить отсечённые пиксели»
  включено и выключено. «С учётом содержимого» вызывает новую команду `image.cropContentAware`: края
  заполняются отдельным слоем, исходные слои сохранены, один шаг отмены.
- **Перо и контуры (VT-44).** Добавление/удаление узла наведением, продолжение открытого
  контура с любого конца (Esc возвращает его), Alt, Ctrl (Стрелка), Shift, стрелки и ручки,
  изгиб сегмента одним шагом и его отмена.

Замер палочки на синтетических 24 Мп (RGB8, сплошной белый кадр — лучший случай):

```powershell
vetro\dist\milestone3\VetroParameterTests.exe .\vetro\build\qa-milestone3 --benchmark-only
```

Отчёт — `wand-perf.txt`: точечный образец 195,3 мс, 3×3 — 203,7 мс, во время 3×3
отрисовано 11 кадров, самый длинный — 13,4 мс. Образец крупнее 1×1 читает весь документ:
предел — 130 Мп (все документы, которые собирает CPU-композитор); больше — ошибка, а не
молчаливый отказ.

`cargo xtask perf --quick` относится к эталонной egui-оболочке: бюджеты в quick-режиме не
применяются, сравнение с macOS-baseline пропущено; это не замер оболочки Vetro.

### Команда кадрирования с заполнением

`image.cropContentAware` зарегистрирована в движке; обычная `image.crop` не менялась.
Тесты: `cargo test -p photocraft-engine --test content_aware_crop` и
`cargo test -p photocraft-engine --lib image_cmds::tests` (27 регрессий), полный `panic_hunt`.
Новый выходной кадр ограничен 64 Мп; синтез с прокси до ~1,1 Мп, пиксели старого
холста и намеренная прозрачность не заменяются. Новая текстура лежит отдельным слоем.

```powershell
vetro\dist\milestone3\VetroParameterTests.exe .\vetro\build\qa-milestone3 --crop-benchmark-only
```

Синтетический RGB8, исходник 5500×4000, выход 6000×4000: обычное кадрирование 52,3 мс;
с заполнением — 4746,7 мс, 233 кадра UI, самый длинный 60,9 мс. Это единичный замер
равномерного цвета, не доказательство бюджета кадров или качества на любой фотографии.
Отчёт `crop-perf.txt`. CPU/GPU Вехи 3 после подключения — 2064/2066 проверок.

## Вехи 4–5 (`VetroBrushLayerTests`, `VetroTextTests`)

```powershell
.\vetro\build.ps1 -Tests -OutputDir .\vetro\dist\milestone5
ctest --test-dir vetro/build --output-on-failure
$env:VETRO_TEST_GPU = '1'
.\vetro\dist\milestone5\VetroBrushLayerTests.exe .\vetro\build\qa-milestone4-gpu
.\vetro\dist\milestone5\VetroTextTests.exe .\vetro\build\qa-milestone5-gpu
```

Запускать наборы с буфером обмена последовательно: тесты используют отдельную оконную
станцию и рабочий стол, но две копии тестового процесса могут открыть одну служебную
станцию. Окна остаются скрытыми; пользовательский экземпляр приложения не участвует.
Без `VETRO_TEST_GPU` выполняется CPU-путь. Снимок `*-render-proof.png` проверяет красный
пиксель из последней ревизии; GPU-вариант также требует настоящую общую текстуру.

Веха 4: 259 проверок CPU / 260 GPU. Проверяются реальные обработчики палитры и панелей,
выбор набора и отпечаток кисти, маски с модификаторами, серый просмотр маски,
замки/метки, живые свойства коррекции и отмена, каналы Уровней и сброс набора,
массивы цветового баланса, импортированная карандашная Кривая и переход к точкам,
глазки эффектов/фильтров, Alt-перенос эффектов, наложение конкретного смарт-фильтра и
перестановка фильтров. На 8/16/32 бит проверяются живой штрих Штампа до отпускания
кнопки, один шаг истории, наложение источника без изменения истории, Заплатка и
Перемещение с учётом содержимого. Русские снимки: Кривые/маски, Кисти, палитра ПКМ.

Веха 5: 607 проверок CPU / 608 GPU. На 8/16/32 бит: кириллица, emoji, новая строка,
геометрия курсора в индексах Unicode, Ctrl+A/C/V, Home/End, локальная отмена,
Ctrl+Enter/Esc, одна запись истории, Undo/Redo, щелчок по существующему тексту и
абзацная рамка с переносом. Проверяется сохранение существующих начертаний при
вставке и вертикальный текст. Отдельная проверка завершает ввод при смене документа
с ещё не отрисованным последним символом. Выделение проверяется по настоящим пикселям
кадра, а не только по состоянию редактора. Снимки: выделение, «Символ», холст.

Мост: 25 тестов; clippy всех целей без предупреждений, форматирование, 30 проверок
слоёв зависимостей, 24 проверки WebAssembly и отдельная сборка моста для wasm.
Полный прогон движка: 1716 прошедших тестов, 19 пропущенных; проверка меню — 631/631.
Регрессии Вех 1–3 в той же сборке: 304 / 330 / 2064 проверок CPU.

Предпросмотр отпечатка ограничен 256×256, шрифта — 512×128; выделение текста и
геометрия курсора — до 32768 символов Unicode. «Авто» Уровней/Кривых использует
гистограмму уменьшенного изображения (до 256 px по стороне) слоёв ниже коррекции.
Просмотр маски сохраняет исходный документ; он не меняет сохранение, миниатюры или Undo.
Карандашные Кривые получают точки через публичный алгоритм движка для просмотра;
исходная карта сохраняется до явной правки.

```powershell
.\vetro\dist\milestone5\VetroBrushLayerTests.exe .\vetro\build\qa-milestone4 --benchmark-only
```

Синтетический RGB8, 6000×4000 (24 Мп), 60 положений источника Штампа, окно 128×128:
среднее 0,538 мс, максимум 2,768 мс. Отчёт `retouch-perf.txt`. Это замер наложения
источника; он не измеряет полный штрих с восстановлением и не подтверждает бюджет
всего кадра интерфейса.

## Пробы issues (`VetroIssueProbe`)

Не входит в ctest. Воспроизводит в настоящих обработчиках оболочки дефекты из issues
оригинального репозитория и подозрения по Вехам 4–5; каждая проба печатает
`REPRODUCED` или `not reproduced` с цифрами и не роняет запуск:

```powershell
.\vetro\dist\milestone5\VetroIssueProbe.exe .\vetro\build\qa-probe
```

Сводка результатов и источники — [ISSUES.md](../ISSUES.md). Когда тикет Вехи 9 закрыт,
его проба переносится в набор ctest как проверка.


## Исправления VT-70…VT-75; начало Вех 6–7 (2026-10-14)

Актуальная сборка этой итерации:

```powershell
.\vetro\build.ps1 -Tests -OutputDir .\vetro\dist\milestone7
ctest --test-dir vetro/build --output-on-failure
```

В ctest теперь семь наборов. Новые:

- `milestone9` / `VetroMilestone9Tests`: завершение пустого текста и форматирование
  пустого слоя; возврат инструмента после двойного щелчка, автоматического завершения
  и смены сглаживания; сброс фазы каретки;
  панели выравнивания, направления, регистра, кернинга и переносов, обновление при
  смене слоя и переходе каретки в другой абзац; все 12 разделов настроек кисти,
  группы и зависимость «Минимум» от Control; пять реальных кнопок замков,
  сохранение прокрутки и раскрытых эффектов по документам; Заплатка внутри,
  снаружи и в отверстии выделения; имена новых документов, коррекций и заливок.
- `milestone6` / `VetroViewTests`: создание/перемещение/удаление направляющих настоящими
  обработчиками мыши, блокировка, Esc и Undo; макет из строк/столбцов через свой
  диалог; единицы и числовая позиция в сантиметрах; попадание в повёрнутую
  направляющую; привязка выделения, подразделений сетки и жеста Move; VT-63 —
  свойства холста без выбранного слоя, изменение ppi без ресэмплинга, размера,
  переключатели и отмена быстрого действия. Геометрия интерфейса дополнительно
  проверяется при 5120×1440, 7680×2160 и 300×200; это не отдельный живой прогон
  окна в этих физических разрешениях.

Оба новых набора сохраняют снимки на русском и отдельно проверяют красный пиксель
последней ревизии. GPU-режим требует настоящую общую текстуру (fallback на CPU
не засчитывается):

```powershell
$env:VETRO_TEST_GPU = '1'
try {
  foreach ($suite in 'VetroMilestone9Tests', 'VetroViewTests') {
    & ".\vetro\dist\milestone7\$suite.exe" ".\vetro\build\qa-gpu-$suite"
    if ($LASTEXITCODE) { throw "$suite failed" }
  }
} finally { Remove-Item Env:\VETRO_TEST_GPU }
```

Мост: 27 тестов. Новые проверки имён подтверждают один шаг истории и имя после
Undo/Redo в 8/16/32 бит; геометрии — единицы, подразделения, направляющие и
исключение выбранного слоя из целей. `pc_selection_contains` читает маску, а
`pc_snap_targets` использует `photocraft_engine::snap::SnapTargets`; исходники
движка не менялись. fmt, clippy всех целей с `-D warnings`, слои зависимостей,
24 проверки `xtask wasm` и отдельный wasm-check моста прошли.

```powershell
.\vetro\dist\milestone7\VetroViewTests.exe .\vetro\build\qa-milestone6 --snap-benchmark-only
```

Синтетический 6000×4000 (24 Мп), 32 векторных слоя: подготовка геометрии 0,353 мс;
1000 запросов позиции — 6,698 мс, среднее 0,0067 мс. Отчёт `snap-perf.txt`.
Это замер геометрии, без отрисовки, не доказательство бюджета всего кадра.

Ограничения: VT-57 частичен (маркеры трансформирования, полный набор модификаторов,
расстояния умных направляющих и стили линий ещё не закрыты). VT-58…VT-62 и VT-69
этой итерацией не реализованы. Импорт ABR по-прежнему не покрыт этим новым набором.

368 / 116 проверок (Вехи 1–5, исправления Вехи 9, Веха 6 вместе с VT-63).
